# REACT NATIVE

Framework en JS creado por Facebook
Para crear aplicaciones móviles nativas y multiplataforma a partir de una misma base de código escrita en JS y React 
(Twitch, Insta, Facebook).

## Características
1. Escrito en JavaS, renderizado con código nativo
2. React native permite crear aplicaciones verdaderamente nativas y no compromete experiencias de sus usuarios
3. Componentes de react envuelven codigo natico con API a traves de paradigma UI declarativo de react y JS
4. Vea sus cambios cuando guarde, no se reincia aplicación, se itera rápidamente.

jsx y js 
los lenguajes se conectan por medio de bridge
