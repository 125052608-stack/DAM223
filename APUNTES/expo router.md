EXPO ROUTER
Expo Router: Herramienta que permite simplificar navegación. Las rutas (Archivos) se generan automáticamente a partir de las estructuras de carpetas. Comunicación entre archivos dentro de una carpeta.

TIPOS DE NAVEGACIÓN
Stack (pila): Pila interfaces y con botones de regresar se
Tabs: Opciones debajo de pantalla
Drawer: Lista hamburguesa
Bottom Tabs: 
Navegación anidada: combinación de navegación

ELEMENTOS EXPO ROUTER:
Contenedor de rutas: Carpeta general (app)

rutas Tabs: carpeta donde se guardan rutas tipo tab.
dentro de esta carpeta tendran rutas definidas. En archivo layout
rutas stack: archivos .js dentro de la ruta. define navegacion

BENEFICIOS EXPO ROUTER:

- organización basada en archivos
- Navegacion sencilla 
- compatible con navegaciones stack, tab, drawer
- escalable
- reduce la cantidad de codigo
